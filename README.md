# Beit Lantern proposals

Proposals by crit for **Beit Lantern**, modular slip-cast porcelain Lebanese lantern houses, made with Dav.

- **Website:** https://criticalumami.github.io/beit-lantern-proposals/
- **Beit Lantern Designer:** https://criticalumami.github.io/beit-lantern-proposals/module.html (villages of porcelain modules, technical sheets; three.js r128, no build step)
- **Written proposals:** [crit_proposals/](crit_proposals/)

Design language drawn from *Architectures de Beyrouth 1925–1970, Manuel de restauration* (Beirut Heritage Initiative, 2022). The PDF is not included here; page references in the proposals point to it.

Rule used throughout: no non-porcelain accessories.
